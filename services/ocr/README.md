# NidhiSetu OCR service

A small FastAPI service that reads a scanned FDR / bank guarantee and returns the deposit fields with a
confidence score for each. The API calls it when a scan is uploaded; OCR values are recorded at
`OCR_EXTRACTED` trust only and are always checked by an officer. If this service is down, uploads
still work, just without pre-filled values.

## Endpoints

| Method | Path       | What it does                                                                   |
| ------ | ---------- | ------------------------------------------------------------------------------ |
| GET    | `/health`  | Status and the OCR engine in use (`paddleocr`, `rapidocr` or `tesseract`)      |
| POST   | `/extract` | Multipart `file` (PDF, PNG, JPEG, ≤ `OCR_MAX_MB`). Returns fields + confidence |

`/extract` response:

```json
{
  "fields": {
    "fdr_number": "SBI/FD/2026/104211",
    "bank_name": "State Bank of India",
    "ifsc": "SBIN0005943",
    "amount": 1000000.0,
    "issue_date": "2026-04-01",
    "maturity_date": "2031-04-01",
    "depositor_names": ["AICTE", "SHIKSHA PRASAR TRUST"]
  },
  "confidence": { "fdr_number": 0.98, "amount": 0.97 },
  "low_confidence": [],
  "raw_text": "…",
  "engine": "rapidocr"
}
```

Errors: `413` file too large, `415` not a PDF/PNG/JPEG, `422` file could not be decoded.

## How it reads a scan

1. **Text.** PDFs with a text layer are read directly (pypdfium2). Everything else is rendered to an
   image and run through OCR: PaddleOCR if installed, otherwise the same PP-OCR models through
   RapidOCR on ONNX Runtime (bundled, CPU only), otherwise Tesseract. See `docs/DECISIONS.md` D-022.
2. **Fields.** Rule-based extraction (`app/extract.py`): label matching ("FDR No.", "Principal
   Amount", "Date of Maturity" …), Indian number and date formats, IFSC pattern, and depositor names.
   Confidence combines the OCR score with how well the value matched its expected pattern.
3. **Optional LLM pass.** With `LLM_EXTRACTION=true` and `ANTHROPIC_API_KEY` set, the raw text is also
   sent to Claude (`LLM_MODEL`, default `claude-opus-5-5`) for structured extraction. Its values
   only fill fields the rules missed or read with low confidence. Off by default — no scan text
   leaves the machine unless enabled.

## Configuration

| Variable            | Default           | Meaning                                    |
| ------------------- | ----------------- | ------------------------------------------ |
| `OCR_MAX_MB`        | `15`              | Largest accepted upload                    |
| `LLM_EXTRACTION`    | `false`           | Enable the optional Claude extraction pass |
| `LLM_MODEL`         | `claude-opus-5-5` | Model for the LLM pass                     |
| `ANTHROPIC_API_KEY` | —                 | Required only when `LLM_EXTRACTION=true`   |
| `LOG_LEVEL`         | `INFO`            | Python log level                           |

## Running locally

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt -r requirements-dev.txt   # Windows
# .venv/bin/pip install …                                                # Linux / macOS
.venv/Scripts/python -m uvicorn app.main:app --port 8000
```

Optional extras: `requirements-paddle.txt` (PaddleOCR), `requirements-llm.txt` (Claude pass).
In Docker the image installs Tesseract and pre-downloads the models at build time.

## Samples and tests

`samples/` holds 10 synthetic FDR images (all data fictional, watermarked "SPECIMEN · FICTIONAL") and a
`manifest.json` of expected values, generated by `scripts/generate_samples.py`.

```bash
.venv/Scripts/python -m pytest
```

`tests/test_samples.py` runs every sample through the real engine and checks each field against the
manifest; on the current models all 70 fields match.
